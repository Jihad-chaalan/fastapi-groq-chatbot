# FastAPI + Groq Chatbot

A simple chatbot API using FastAPI and Groq's LLM.

## Features

- Chat with Groq models
- Pydantic validation for request/response
- Token usage tracking
- system prompt controlling

## Setup

### 1. Clone & enter folder

```bash
git clone https://github.com/yourusername/fastapi-groq-chatbot
cd fastapi-groq-chatbot
```
